# club1-dashboard

Ежедневно обновляемый дешборд продаж билетов Club №1 (StandUp Arbat).
Страница зашифрована паролем (AES-256-GCM, PBKDF2); содержимое доступно
только команде. Обновляется каждое утро прогоном direct-daily.

Исходники конвейера: `~/Projects/standup-vault/dashboard/` (не в этом репозитории).
